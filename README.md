# A collection of reusable, multi-format knowledge bases from our published papers

This repository contains a curated collection of knowledge bases that have been used in my peer-reviewed publications. The knowledge bases are provided in multiple formats to support reuse and experimentation, including:

-	🧩 Feature Models
-	📐 MiniZinc Models
-	📄 Other structured representations (to be added)

Each knowledge base is organized with metadata and references to the corresponding paper(s). This resource is intended to support reproducibility, facilitate benchmarking, and encourage further research in knowledge-based systems.
